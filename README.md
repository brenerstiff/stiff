# Consultoria Hub

Mini sistema web (frontend puro) para gestão de alunos da consultoria com:

- **Mini CRM**: cadastro, edição, busca, filtro por status, progresso e histórico de contato.
- **Mural de recados**: publicação de avisos com prioridade, público-alvo, fixação e data de expiração.
- **Persistência local**: todos os dados ficam salvos no `localStorage` do navegador.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Cadastre alunos e recados pelos formulários.
3. Use o campo de busca e filtro para encontrar alunos rapidamente.
4. Clique em **Registrar contato** para atualizar o último contato com o aluno.

## Observação

Este projeto é um MVP sem backend. Se quiser, dá para evoluir para:

- autenticação de equipe;
- múltiplos usuários/perfis;
- banco de dados e API;
- notificações automáticas.
